# XAI KLTN - Agent Rules & Guidelines

Hệ thống thực nghiệm HCI cho đề tài Explainable AI (XAI) và Thiên kiến tự động hóa xây dựng trên Next.js và Supabase.

## Project Essentials
- **Package Manager**: `npm`
- **Database ORM**: Prisma (PostgreSQL / Supabase)
- **Primary Commands**:
  - Development Server: `npm run dev`
  - Build Command: `npm run build` (auto-generates Prisma Client and compiles the Next.js app)
  - Schema Sync: `npx prisma db push`
